# Definity Telegram Automation 🤖

A Python-based utility designed to automate interactions, alerts, and messaging through the Telegram API for the Definity ecosystem.

### 🛠️ Tech Stack
* **Language:** Python 3.x
* **Libraries:** `python-telegram-bot` (or `Telethon` / `Pyrogram`), `requests`

### 🚀 Getting Started
1. Clone the repository: `git clone https://github.com/peddrof/Definity-Telegram-Automation.git`
2. Install dependencies: `pip install -r requirements.txt`
3. Create a `.env` file and add your Telegram Bot Token: `TELEGRAM_TOKEN=your_token_here`
4. Run the script: `python main.py`
